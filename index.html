What I've built

Every project below is a public repo, and every number links back to its README or study.

AI Security · CI Gate ↗

aisec-suite

CI security gate for the inputs AI agents trust: MCP tool metadata, agent memory files and RAG documents. One aisec scan with SARIF output and a reusable GitHub Action. Its structural tool-poisoning detector catches 53.7% of my own held-out attacks but 14.0% of attacks written by other researchers (MCPTox and MCP-Poison-Bench, pre-registered and run once; a naive regex catches 6.8-10.5%), with no false positives on the attacked servers' 362 real tools. It survives look-alike-letter and encoding obfuscation, and its reachability check follows tool calls into Godot and Unity engine plugins.

Python · SARIF · GitHub Actions PyPI 0.4.0
Empirical Study ↗

MCP scan study + mcpaudit

Hand-labelled scan of 135 public MCP-server repos. No real tool poisoning found. mcpaudit's scope rule was right 37.5% of the time, so I rewrote it. On a blind-labelled fresh corpus of 45 repos, precision went from 40% to 72.7% (16/22) and all true findings were kept.

Static analysis · Wilson CIs pyhroff-mcpaudit 0.8.0
Agent Memory & RAG ↗

memsentry · ragsentry

Static scanners for injected instructions in agent memory/context files (CLAUDE.md, .cursorrules) and RAG source documents. On 170 real context files, memsentry 1.2.0 cut false positives from 61 to 5.

Python · static analysis PyPI 1.2.0 · 1.1.0
Detection Engineering ↗

SOC Parallax

Behavioural detection platform: per-entity baselines, an attributable risk score and MITRE ATT&CK mapping from a versioned rulebook. On 278 real EVTX attack samples, 29.5% reach medium severity or higher (27.3% held-out), and nothing reaches high on held-out benign data.

FastAPI · Neo4j · Next.js 278 EVTX samples
Agentic AI ↗

OSIRIS

Model-agnostic personal assistant runtime I use daily: 8 LLM providers behind one router with failover, 9 tool-scoped agents and embedding memory. Traced a local-model slowdown to Ollama's thinking mode and fixed it in a native adapter (about 100 s to 10 s per call, measured live).

Python · SQLite · embeddings daily use
Agent Observability ↗

loopcheck

Waste auditor for hand-rolled agent tool-calling loops: duplicate calls, thrashing and semantically redundant calls, with regression comparison and fleet reports.

Python · CLI install from source
