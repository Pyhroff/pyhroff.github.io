MCP tool-poisoning detector

Paste a tool definition (as JSON) and see how the structural detector from aisec-suite scores it. Everything runs in your browser using Pyodide; nothing you paste is sent anywhere.

What this is, and is not. It is a review aid. On attacks I wrote, held out from development, it finds 53.7%; on attacks written by other researchers it finds 14.0%; it flagged 2 of 3,974 real tool descriptions (0.05%). It does not catch attacks phrased as ordinary documentation (see the "missed" example). A clean result is not a safety guarantee. Method and caveats: the study and the write-up.

Choose an example or paste a tool to begin.

The detector is aisec/poison.py (standard library only), copied unmodified apart from removing its package import into playground/poison.py. The scoring is explained in that file's docstring. Accepts MCP's inputSchema or input_schema. Input is limited to 20,000 characters.

Python is loaded from the jsDelivr CDN (Pyodide 0.27.7). If it cannot load, install the tool instead: pip install "aisec-suite[core]".
